# Plan Local Food

Read `references/food-planning-rules.md` when composing a multi-day itinerary.

1. Extract taste, dietary restrictions, allergies, meal budget, and desired food experiences.
2. Attach breakfast, lunch, dinner, markets, and snacks to the day's existing area instead of creating long detours.
3. Give representative dishes or restaurant types, a per-person range, expected waiting risk, and a clickable search entry.
4. Treat an unverified restaurant as a candidate. Never invent current hours, ratings, availability, or a completed reservation.

This is an original query-and-planning implementation inspired by publicly described food-planning patterns in SkillHub's travelassistant. Do not copy or depend on unpublished prompt text.
