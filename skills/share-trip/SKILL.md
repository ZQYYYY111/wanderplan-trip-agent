# Share Trip

Create an opaque share token with an expiry or revocation path. Default to a read-only view. Remove identity documents, contact details, payment information, booking references, private notes, and precise personal location data.

Treat friend edits as proposals. Show a diff and require the trip owner to accept or reject each proposal before it changes the main itinerary.
